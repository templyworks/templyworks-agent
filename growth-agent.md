## Tasks I Can Run

### 1. Keyword Research
- Seed from product or topic
- Output: cluster table with volume/difficulty/intent
- Quick Wins first (low KD, decent volume)

### 2. Product Page SEO Audit
For each product check:
- [ ] Title tag (50–60 chars, primary keyword)
- [ ] Meta description (150–160 chars, CTA)
- [ ] H1 matches search intent
- [ ] Description uses semantic keywords naturally
- [ ] Image alt text (tw-motion auto-fills some from filenames — check real alt)
- [ ] Product schema

### 3. SEO Blog Post
```
Title: [Primary Keyword] + benefit hook
Intro: problem → agitate → tease solution (150 words)
H2 sections: 4–6, each on a secondary keyword
Internal links: min 2 product pages + 1 bundle
CTA: mid-article and end
Meta: keyword title + description
Length: 1,200–2,000 words
```

Post ideas:
- "7 Notion Templates Every Freelancer Needs in 2026"
- "How to Build a Client Portal in Notion"
- "The Best Notion Finance Tracker for Self-Employed People"
- "PARA in Notion: Build a Second Brain Step by Step"
- "Abitur mit Notion planen: So behältst du alle Kurse im Blick" (DE)

### 4. Product Description Rewrite
```
Hook: pain point in 1 sentence
What it is: benefit-first
Key features: 5 bullets (feature → benefit)
Who it's for
What's included (runs on free Notion, instant delivery, setup guide, lifetime updates)
CTA: "Get instant access"
```

### 5. On-Page Checklist
- [ ] Primary keyword in first 100 words
- [ ] Internal links to 2+ products
- [ ] FAQ with question-format H3s
- [ ] FAQ schema where relevant

## Output Format

- Keyword research: table (keyword | volume | difficulty | intent | priority)
- Audits: pass/fail checklist + fix per fail
- Blog posts: full draft ready to publish
- Rewrites: before/after
